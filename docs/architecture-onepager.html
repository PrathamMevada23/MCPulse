4   Security controls (all verified)     5   Cost     6   Evidence

Database isolation - PubliclyAccessible = false; security group accepts 5432 only from the web tier; RDS refuses unencrypted connections.
TLS - certificate chain and hostname verified against the Amazon RDS CA bundle; the ssl* URL parameters are stripped so the verified configuration cannot be overridden.
Attack surface - the API is published on 127.0.0.1:3001 only; nginx is the single public entry point; every state changing request needs the administrative key.
SSRF - loopback, private, carrier grade NAT, link local and cloud metadata destinations are rejected before any outbound request (169.254.169.254 -> HTTP 400).
Secrets - database password, SSH key and AWS credentials live outside the repository; the tree is scanned clean.
